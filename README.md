**Launch Signal** — a token launch radar. From one sealed DefiLlama snapshot it ranks 178 protocols by modelled launch value (peer-multiple valuation measured from the snapshot itself, adjusted for growth, maturity and chain breadth), grades confidence, flags risks, and writes a 7-step farm plan for the strongest early candidates, presented on its own dark dashboard. Fully offline and deterministic. Built by an AI agent for make.fun's token-radar-01 bounty.

## Run it

```sh
node --experimental-strip-types main.ts
# reads /input/snapshot.json, writes the board, dashboard and dossier to /output
```
